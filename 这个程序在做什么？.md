## 这个程序在做什么？

它是一条**从 PDF 法规文本里抽「规则」**的流水线，按顺序做这些事（`--run all` 会全跑一遍）：

| 步骤          | 作用（通俗说）                                              |
| ------------- | ----------------------------------------------------------- |
| **parse**     | 把 PDF 读成按页文字，拼成全文                               |
| **profile**   | 粗看全文：像不像法规、有没有公式/处罚等                     |
| **plan**      | 决定按什么粒度分段（默认按「条」等）                        |
| **segment**   | 把全文切成多段 **segment**（便于后面逐段问模型）            |
| **extract**   | 每一段调一次 DeepSeek，抽出结构化字段（义务、对象、例外等） |
| **normalize** | 把规则类型、措辞等做一点统一                                |
| **evaluate**  | 占位评估报告（你还没标金标的话主要是空壳）                  |

---

## 运行结果是什么？

主要是两类：

1. **中间/结构化 JSON**：画像、分段列表、抽到的规则列表、归一化后的规则列表。  
2. **表格**：抽取结果和归一化结果会各导出一份 **CSV**，方便用 Excel 打开。

PDF 文件名（不含后缀）会当作 **`stem`**，例如 `target_file.pdf` → 下面文件里的 **`target_file`**。

---

## 在哪找？（都在项目目录 `rule_extraction_project` 里）

以 `target_file.pdf` 为例：

| 位置                                                  | 内容                   |
| ----------------------------------------------------- | ---------------------- |
| **`data/interim/target_file_parsed_document.json`**   | 解析后的全文、按页文本 |
| **`data/processed/target_file_profile.json`**         | 文档画像               |
| **`data/processed/target_file_plan.json`**            | 分段策略               |
| **`data/processed/target_file_segments.json`**        | 所有 segment           |
| **`data/processed/target_file_extracted.json`**       | 模型抽到的规则（原始） |
| **`data/processed/target_file_normalized.json`**      | 归一化后的规则         |
| **`outputs/tables/target_file_rules.csv`**            | 抽取结果表             |
| **`outputs/tables/target_file_rules_normalized.csv`** | 归一化结果表           |
| **`data/eval/target_file_eval_report.json`**          | 评估占位报告           |

**你最常看的**：想快速看抽出了什么 → **`outputs/tables/target_file_rules_normalized.csv`**（或 `target_file_rules.csv`）；想自己程序处理 → **`data/processed/target_file_normalized.json`**。
